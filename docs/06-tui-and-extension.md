# 终端交互与运行时集成

桌面端用来集中配置和对比测试，而在日常写代码时，所有交互都无缝融入你的终端。

---

## 终端模型选择器 (`Alt + P` 或 `/models`)

在任何 Pi 编码会话中，随时按下快捷键 **`Alt + P`**（或者输入 `/models`），终端会直接弹出全键盘驱动的交互式选择菜单：

```text
  Pi Model Selector
  [最近使用]   [按提供商]   [按模型系列]
  --------------------------------------------------
  > 输入关键字模糊检索...
  --------------------------------------------------
  * claude-3-7-sonnet-20250219 (a6api-claude)   [128k]
    gemini-3.7-flash-high-cli  (bearlab-gemini) [1M]
    deepseek-chat              (a6api-DeepSeek) [64k]
  --------------------------------------------------
  [↑/↓] 移动   [Enter] 确认切换   [Tab] 切换分类   [Esc] 退出
```

### 三大分类 Tab
1. **最近使用**：系统会记住你的使用习惯。最近成功调用过的模型会自动排在最前面，高频模型触手可及。
2. **按提供商**：按你的渠道（如 `a6api-claude`、`my-deepseek`）折叠聚合，方便按站点挑选。
3. **按模型系列**：按品牌（Gemini、Claude、DeepSeek 等）归类，方便跨渠道横向切换同一系列的不同档位。

### 快捷键一览
- **`↑` / `↓`**：上下移动光标。
- **`Tab` / `Shift+Tab`**：在三大分类间切换。
- **直接打字**：即时模糊检索，支持同时搜模型名或渠道名。
- **`Enter`**：选中并切换当前会话的模型。
- **`Esc`**：取消退出。

## 控制台命令列表

在 Pi 会话中可以直接执行以下管理指令：

- **`/provider list`**：在终端打印当前已加载的所有渠道名称和模型统计。
- **`/provider reload`**：如果你刚在桌面端修改或添加了新模型，在终端敲入这条命令，即可**毫秒级重载配置，无需重启 Pi**。
- **`/models`**：调出上面的模型选择菜单。
- **`/model-manager`**：一键唤起桌面可视化管理窗口。

---

## 智能体自主感知：`provider_list` 工具

除了给开发者用的命令，扩展还向底层的 LLM 注入了一个名为 **`provider_list`** 的系统工具。

当 Pi Agent 在处理复杂任务需要派发子代理（Subagent）或自主挑选更便宜、更快的模型时，它可以自主调用这个工具，了解当前环境下有哪些渠道可用，实现更高程度的自动化。

## 请求追踪与超长恢复机制

扩展在底层自动为你处理了两件麻烦事：

1. **会话链路追踪 (`x-session-id`)**：每次调用自动携带唯一的会话 ID。如果遇到中转站吞字或报错，拿着这个 ID 找中转站管理员，对方能立刻在网关日志里精确定位到这笔请求。
2. **上下文超长自动恢复**：多轮对话后如果超出模型的最大上下文，不同中转站返回的报错千奇百怪。扩展内置了自适应正则拦截，会自动把各色报错转化为 Pi 原生识别的标准异常，促使 Pi 自动触发滑动窗口压缩与摘要提炼，防止会话直接崩掉。
