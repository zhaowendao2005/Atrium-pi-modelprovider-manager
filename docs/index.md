# Pi Model Provider Manager

如果你正在使用 Pi 编码智能体，并且手上收集了许多不同的 API 中转渠道，希望以灵活、实惠的方式自由调用各种模型，这个工具就是为你准备的。

---

## 为什么做这个项目

很多开发者向往“模型自由”：不想被少数几家大厂的昂贵订阅捆绑，而是手上收集了十几个不同的中转站点，按市场真实用量和价格调用模型。

但在实际使用中，有两个长期困扰的问题：

1. **配置文件臃肿且难维护**  
   Pi Agent 本身具备极其强大的底层适配能力，它的配置项非常细致，几乎能适配市面上所有的中转协议与参数变体。然而，手动维护数百行的配置文件不仅门槛高、易出错，当添加了数十个模型后，文件视觉上极其冗长，排查一个参数是否生效十分费力。
2. **不同渠道质量良莠不齐，缺乏统一检验手段**  
   中转站的质量千差万别：有的首字响应极慢，有的存在假流式输出，有的甚至存在掺水或截断。缺乏工具直观比对不同渠道在速度、首字延迟（TTFT）和代码生成质量上的真实表现。

为了解决这两个问题，我们构建了 **Pi Model Provider Manager**：
- **一个直观的可视化桌面窗口**：轻松接入和管理你的所有渠道与模型，把复杂细致的配置转化为清晰的界面操作，随改随存。
- **一套原创的模型测试与对比工作台**：在完全隔离的本地沙箱中，让多个模型在同一标准下同台竞技，直观查看双轨 TPS 吞吐、微观网络耗时和真实工具调用表现。

## 我们主要做了什么

### 1. 桌面可视化管理窗口
专为收集大量中转渠道的用户设计。支持快速检索、分类归档、启用切换，以及一键套用官方预设模版。所有配置直接写入本地 SQLite 数据库，告别手写 YAML 和 JSON 的烦恼。

### 2. 细致配置的可视化呈现
Pi Agent 允许对请求的方方面面进行深度定制。我们在界面中保留了这些强大的控制力（包括 9 种协议切换、请求头注入、思考强度映射和兼容性补丁），同时引入了 **有效配置推导** 与 **字段速查抽屉 (DocsDrawer)**。点击任意选项旁的帮助按钮，就能清楚看到当前模型最终生效的真实值和来源依据。

### 3. 原创的模型评测与对比工作台
这是我们投入最多心力的原创模块。我们为你提供了一个横向对比评测场：
- **5 种自适应分屏布局**：从单卡片深度审计到多列横向实时对比。
- **双轨 TPS 监控**：区分“含首字 TPS”（反映真实交互体感）与“不含首字纯生成 TPS”（反映上游算力物理上限）。
- **微观网络时序分析**：精确拆解 DNS、TCP 握手、TLS 协商与 TTFB 首字延迟。
- **真实沙箱穿透**：模型直接在隔离目录中写代码、跑测试，你可以随时在系统文件管理器中查看真实生成产物。
